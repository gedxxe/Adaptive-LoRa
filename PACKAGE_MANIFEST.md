# Package contents

This repository contains Adaptive-LoRa firmware for the Heltec WiFi LoRa
32 V3.4 (ESP32-S3/SX1262), test tools and bilingual guides.
[Firmware setup](README.md) · [Builds and test results](docs/en/PROGRESS.md)

Generated binaries, toolchain caches, private board backups, local
credentials and full-text research PDFs stay outside the publication.
See [third-party rights](THIRD_PARTY.md)
and the [figure register](docs/references/FIGURE_SOURCE_REGISTER.md).

The [progress archive](docs/en/PROGRESS.md#past-work)
keeps the early package and migration records.
